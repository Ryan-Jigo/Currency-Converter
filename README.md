# 💱 Currency Converter

A simple and responsive web application that allows users to convert currencies using real-time exchange rates. The application provides an intuitive interface for selecting currencies, entering amounts, and instantly viewing converted values.

## 🚀 Features

* Real-time currency conversion
* Support for multiple international currencies
* User-friendly and responsive interface
* Instant conversion results
* Currency selection using dropdown menus
* Error handling for invalid inputs
* Lightweight and fast performance

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
* Currency Exchange API

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Ryan-Jigo/Currency-Converter.git
cd Currency-Converter
```

### Run Locally

Simply open the `index.html` file in your browser:

```bash
start index.html
```

or use VS Code Live Server for a better development experience.

## 📖 Usage

1. Enter the amount you want to convert.
2. Select the source currency.
3. Select the target currency.
4. Click the **Convert** button.
5. View the converted amount instantly.

## 🌍 How It Works

The application fetches exchange rate data from a currency exchange API and calculates the converted value based on the latest available rates. Real-time exchange rate APIs are commonly used in currency converter applications to provide accurate conversion results.
